# 検索の使い方

## キーワードの入力

検索欄にキーワードを入力して「検索」を押します。キーワードを入力しない場合は、条件に合う動画をすべて表示します。

- 空白(半角・全角)で区切ると、複数のキーワードとして扱います。
- `"` で囲んだ部分は、空白を含めて1つのキーワードとして扱います。例: `"AAA BBB"` は `AAA BBB` を検索します。
- 英字の大文字と小文字、全角と半角、カタカナとひらがな、漢数字と算用数字は区別しません。

## AND検索とOR検索

複数のキーワードを入力した場合の条件を選択します。

| 方式 | 動作 |
| --- | --- |
| AND検索 | すべてのキーワードを含む動画を表示します。初期値です。 |
| OR検索 | いずれかのキーワードを含む動画を表示します。 |

## 検索対象

キーワードを検索する項目を選択します。複数選択できます。1つも選択しない場合、キーワードを入力すると何も表示されません。

- タイトル(初期値)
- タグ
- 概要欄
- 投稿者

## 絞り込み

| 項目 | 動作 |
| --- | --- |
| 限定公開 | 限定公開の動画だけを表示します。 |
| 削除済み | 削除済み、非公開の動画も表示します。 |
| すべて | ボイパ対決と素材の両方を表示します。初期値です。 |
| ボイパ対決 | ボイパ対決の動画だけを表示します。 |
| 素材 | 素材の動画だけを表示します。 |
| AIによる分類 | AIによる分類結果を元にした一覧を表示します。 |

## 並び替え

| 項目 | 順序 |
| --- | --- |
| 投稿日時が新しい順 | 投稿日時の降順です。初期値です。 |
| 投稿日時が古い順 | 投稿日時の昇順です。 |
| 再生数が多い順 | 再生数の降順です。 |
| 再生数が少ない順 | 再生数の昇順です。 |
| 高評価が多い順 | 高評価数の降順です。 |
| タイトル昇順 | タイトルの昇順です。 |
| タイトル降順 | タイトルの降順です。 |
| ランダム順 | 順序を無作為に並び替えます。 |
