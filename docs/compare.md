# 動画比較

複数の YouTube 動画を、開始位置をそろえて同時に再生します。ニコニコ動画は対象外です。メニューの「動画比較」から開きます。

## 動画の追加

- 入力欄に YouTube の URL または動画 ID を入力して「追加」を押します。
- ログイン中は「お気に入りから追加」で、お気に入りの YouTube 動画から選択できます。
- 追加できる動画は最大 20 本です。

## 再生の操作

| 操作 | 内容 |
| --- | --- |
| 同時再生 | すべての動画を同時に再生します。 |
| 停止 / 再生 | 一時停止と再開を切り替えます。 |
| クリア | 並べた動画をすべて削除します。 |
| 表示サイズ | 小(320)、中(480)、大(640)から選択します。 |
| くっつけて表示 | 動画の間隔を詰めて表示します。 |
| ずれを自動で補正 | 再生中のずれを自動で補正します。 |

## 動画ごとの設定

- 表示: 全体、左半分、右半分から選択します。
- ミュート: 動画ごとに音を消します。
- 並び順: 「前へ」「後ろへ」で入れ替えます。
- 開始位置(秒): 「今の位置から始める」で、再生中の位置を開始位置にできます。

## 合わせ方

| 方式 | 内容 |
| --- | --- |
| 基準位置で合わせる | 初期値です。動画ごとの基準位置をそろえて再生します。 |
| 開始位置で合わせる | 動画ごとに指定した開始位置から再生します。 |

### 基準位置

基準位置は、Bad Apple!! の「流れてく 時の中ででも」の「ながれ」の頭の位置です。動画が「ながれ」より後から始まる場合は、マイナスの値を指定します。

- 基準位置は全ユーザー共通で保存されます。保存にはログインが必要です。
- 値を空にして保存すると削除します。
- 「基準からの開始位置(秒)」で、全体の開始位置をまとめてずらせます。マイナスの値を指定すると、基準より前から再生します。

## 共有と保存

- 「URLをコピー」で、現在の並びを再現できる URL をコピーします。
- ログイン中は、名前を付けて「マイページに保存」できます。保存した比較は、マイページから開き直して上書きできます。

## 録画

「録画開始」で比較の画面を録画し、「録画停止」で保存します。PC の Chrome または Edge で利用してください。環境によっては音声が Opus 形式で保存され、Windows 標準のプレイヤーで再生できない場合があります。
