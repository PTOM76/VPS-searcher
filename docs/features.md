# その他の機能

## 表示モード

ナビゲーションバーのアイコンで、リスト表示とマトリックス表示を切り替えます。検索条件は切り替え後も引き継がれます。

## ダークモード

ナビゲーションバーのアイコンで、ライトモードとダークモードを切り替えます。

## 言語

ナビゲーションバーの「Language」から、日本語、English、中国語、韓国語を選択します。

## 動画の操作

各動画の下に、次のリンクがあります。

- 報告: 動画の報告ページを開きます。
- URLコピー: 動画の URL をクリップボードにコピーします。

## 統計データ

「情報」のページから「統計データ」を開くと、年度別の投稿数などを確認できます。「情報」のページには、収録している動画の件数(総計、ボイパ対決、素材)も表示されます。

## フィード

新着情報を、次の URL で購読できます。

```
https://vps-search.pitan76.net/rss.xml
https://vps-search.pitan76.net/feed.atom
```
