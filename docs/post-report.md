# 動画の送信と報告

## データ送信

ボイパ対決と素材の動画を、このサイトへ追加するために送信できます。「データ送信」のページを利用します。

- 送信できる URL は、YouTube の動画または再生リスト、ニコニコ動画の動画です。ニコニコ動画は `sm` で始まる動画 ID でも送信できます。
- 種類として「ボイパ対決」または「素材」を選択します。
- 送信された動画は、運営がボイパ対決または素材に当たるかを審査してから追加します。比較動画などは、現時点では採用しません。

## 動画の報告

各動画の「報告」から、次の項目を選択して送信します。

- 比較などの動画である、または関係のない動画である
- 動画が削除、非公開である
- 法律に反する動画である
- 種類(ボイパ対決/素材)が間違えている
- その他

「その他」を選択した場合は、理由を記入してください。
